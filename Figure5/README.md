# Figure 5

This directory contains the processed input data and custom scripts used to reproduce the mutation-enrichment and recurrent-target analyses shown in Figure 5.

## Panels

- Figure 5a: Genome-wide identification of recurrently mutated genes.
- Figure 5b: Mutational-spectrum and gene-level selection analyses.
- Figure 5c: Exploratory enrichment analysis of missense mutations in hybrid and uniparental two-subunit protein complexes.

## Directory structure

- `data/`: processed mutation, gene and protein-complex data
- `scripts/`: enrichment, statistical-analysis and plotting scripts
- `output/`: reproducible summary tables and plots

The current Figure 5c plot uses nominal chi-square P values and mutation excess values from the final analysis workbook. Highlighted complexes are treated as exploratory candidates. Final panel assembly was performed in Adobe Illustrator.
