# Figure 6

This directory contains the processed input data and custom scripts used to reproduce the genetic-background analysis shown in Figure 6.

## Panels

- Figure 6a: Circular genome and ancestry-frequency analysis of hybrid backgrounds associated with recurrent HSP104 mutations.
- Figure 6b: Prion phenotyping of parental strains and recombinant segregants using the ade1-W244* reporter on YPD, SC–Ade, and guanidine-HCl.
- Figure 6c: Functional reconstruction and prion phenotyping of evolved HSP104 variants.

## Notes

Figure 6a was generated using Python and R scripts for ancestry-block preparation, circular genome plotting, and genome-wide ancestry-frequency analysis. The complete processed genomic coordinates are provided in the Source Data file associated with the article.

Figures 6b and 6c consist of experimental plate images and did not require custom plotting code.

Final panel assembly, labels, colors, and graphical layout were prepared in Adobe Illustrator.
