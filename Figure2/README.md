# Figure 2

This directory contains the processed input data and custom scripts used to reproduce the quantitative analyses and plots shown in Figure 2.

## Panels

- Figure 2a: Phenotypic characterization of the recombinant hybrid segregants.
- Figure 2b: Spot Assay at different temperatures
- Figure 2c: Thermotolerance of parental strains and recombinant segregants.
- Figure 2d: Competitive-fitness estimates for parental strains, the F1 hybrid and recombinant segregants.


Final panel assembly and author-created graphical elements were prepared in Adobe Illustrator.
